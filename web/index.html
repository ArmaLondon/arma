Live agent log

Arma runs a team of Claude agents (Claude Agent SDK) that map, audit, fix and independently verify a storefront against WCAG 2.1 AA, the standard behind the European Accessibility Act. Automated tools cover only part of WCAG: items marked “needs review” and testing with disabled users remain required.

Arma

Arma gives compliance teams an AI agent team that audits, fixes and verifies their store's accessibility, then hands engineering a ready-to-merge pull request.

The problem

Since June 2025 the European Accessibility Act makes WCAG 2.1 AA (EN 301 549) a legal duty for e-commerce, and French retailers are already being sued. JavaScript overlays fix nothing (FTC fine against accessiBe, 2025). Scanners only catch part of the issues, and compliance teams cannot turn a report into engineering tickets.

  writer ──► pull request + accessibility statement ──► compliance sign-off

Built with the Claude Agent SDK (Python), in-process MCP tools, Playwright + axe-core and git. This page replays a recorded run: no external system is contacted.
