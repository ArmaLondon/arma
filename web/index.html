    Live agent log

    Arma runs a team of Claude agents hosted on Claude Managed Agents that map, audit, fix and independently verify a storefront against WCAG 2.1 AA, the standard behind the European Accessibility Act. Automated tools cover only part of WCAG: items marked “needs review” and testing with disabled users remain required.

    Arma

    Arma gives compliance teams a hosted AI agent team that audits, fixes and verifies their store's accessibility, proves it against a rubric, and hands engineering a ready-to-merge pull request.

    The problem

    Since June 2025 the European Accessibility Act makes WCAG 2.1 AA (EN 301 549) a legal duty for e-commerce, and French retailers are already being sued. JavaScript overlays fix nothing (FTC fine against accessiBe, 2025). Scanners only catch part of the issues, and compliance teams cannot turn a report into engineering tickets.

    The agent team

    Build it. Let it run. Prove it worked. A lead agent hosted on Claude Managed Agents maps the store and sends one auditor per page, in parallel threads. For each WCAG criterion, a developer fixes the source code and an independent tester, who cannot edit and never sees the developer's diff, accepts or rejects each fix with a reason. A rejection goes back to the same developer thread; regressions are rolled back with git; after three attempts an issue goes to a human. A writer drafts the pull request and the accessibility statement.

    Every finding and status change goes through typed tools answered by Arma's own compliance ledger, which enforces the status rules and keeps the audit trail. An independent grader checks the result against a rubric, and an eval measures it against the store's known defects.
